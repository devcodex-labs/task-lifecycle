# HTTP辅助验证

> 此文件是 Task Lifecycle V1 **执行规则**，不是新的需求审批、实际运行记录或额外 API。根依据为用户正式批准的开发需求 V0.18-R2、Usage Contract V0.5-R2 与技术方案 R9-R2。不得以本文覆盖更高优先级的真实用户决定或宿主安全权限。

## 读取条件与职责

**触发**：Feature/Bugfix/Docs 真实涉及HTTP API、用户询问可复用请求文件、变更影响API文档或回归时。

**唯一主责**：WebStorm/JetBrains `.http` 的 off/suggest/generate策略、契约同步与危险请求的独立授权

**直接消费者**：适用A04～07、B03/06/07、DOC专业示例和PoC F/H/M。

**联动 Reference**：`验证与证据分流.md` 定义E4证据；`文件目录版本与跨会话恢复.md` 定义写入和版本安全。

## 适用时逐项执行

1. 先查用户本次明确偏好/经批准项目或工作区策略，仅允许 `off / suggest / generate`；默认 `suggest`。`off` 不主动生成或提示；`suggest` 仅解释可生成的接口/样例/收益/位置和风险，获确认才改项目文件；`generate` 必须有合法有效指令或适用执行偏好。
2. 根据真实当前 API/字段/鉴权/错误/版本/消费者，构建可复用的成功/边界/错误/权限样例；未知 endpoint 或返回类型应明确待证，不造假接口。
3. 生成 `.http` 在用户项目合法位置，变量化 baseUrl/Token 等，禁止打包实际凭证；用户未允许写 `.gitignore`/私有配置不得静默修改。保持环境区分，提醒敏感请求需要真实环境核准。
4. 严格四级状态：`generated`(仅文件存在)、`statically-checked`(实际格式/变量检查)、`requested`(真实请求/响应脱敏记录)、`passed`(预先冻结断言真实执行满足)。任意前一级不得替代后一级。
5. GET/POST/PUT/PATCH/DELETE 不能只依HTTP动词抽象决定是否可执行，需看目标地址、数据/副作用、权限和可回滚性；没有真实权限绝不向生产或个人账户发请求。
6. API需求/实现改变后回查受影响 `.http` /公开文档/示例的契约版本，同步或标识陈旧；仅生成文件不等于验证接口成功。

## 必须拒绝的反例

- 默认 suggest 却直接写用户仓库；调试文件中明文真实Token；成功生成即回报“接口测试通过”；未经许可发POST真实交易；Docs-only修示例时改后端契约。

### 12.3 HTTP 辅助请求策略与产物协议

| 任务/项目有效偏好 | 技术处理 | 验证限制 |
|---|---|---|
| `off` | 不主动建议或生成 `.http` | 用户本次明确要求优先按本次授权处理 |
| `suggest`（默认） | HTTP API 适用时在规划中提出可生成的接口/负例、位置、维护价值和风险，等待合法确认 | 未批准前不改项目中的调试文件 |
| `generate` | 用户当前任务明确要求或项目真实有效偏好批准后，在被允许位置**创建或更新**可用 `.http` | 创建 ≠ 语法校验 ≠ 真实发请求 ≠ 请求结果 passed |

根据真实 API/契约，编排代表性的成功/错误/鉴权/边界请求及适用响应断言。
- 环境地址、Token 等使用变量和私有环境文件，**不得硬编码真实凭证**。
- 有危险副作用的 `POST`/`PUT`/`PATCH`/`DELETE` 不可仅按方法名一概否定，必须依据实际环境、数据与允许的操作分析；**生成文件可合法，实际向真实/生产环境发送须有独立合法授权**。
- 不擅自创建敏感的 `http-client.private.env.json` 示例真实值或把私有文件提交 Git；
- 建议在项目 `.gitignore` 等合法规则中排除私有环境文件，修改忽略规则仍需在范围/权限内。

| 证据层级 | 可声称内容 |
|---|---|
| 已生成 | 文件实际存在、引用真实已批准 API 来源、未被实测 |
| 已静态检查 | 文件语法/变量引用等实际检查通过（按可用工具范围） |
| 已请求 | 记录真实环境、请求/响应、状态、断言、时间、脱敏证据 |
| 已通过 | 事先冻结的实际请求断言有 E4 证据且未违反授权；不代替单元/集成全覆盖 |

参考 JetBrains 官方 HTTP Client（含公共与私有环境文件、响应脚本、CLI 及报告）：https://www.jetbrains.com/help/idea/http-client-variables.html 、https://www.jetbrains.com/help/idea/http-client-cli.html 。
- 具体特性/命令由目标 WebStorm 与真实安装的 HTTP Client/CLI 版本核实，不能把第三方 IDE 的 `.http` 语法误当通用 HTTP 规范。

### 12.4 完整文档与 HTTP 的变更传播

Feature 改了公开 API，应判断 README/Reference/示例/`.http` 是否需要同步；Bugfix 修了错误码/行为，需回核实际对外合同和复现脚本；Docs 修改示例但源 API 不变时不应偷偷改业务实现。任何请求文件和页面在交付前绑定实际实现版本和消费者证据；版本改变后针对受影响部分重新验证。
