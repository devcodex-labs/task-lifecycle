# 校验脚本输出协议（`scripts/validate-config.mjs` stdout）

本文件随插件分发，供「放权类配置：JSON 与校验脚本（消费协议）」第 3 条逐字段核对；原始依据为 FEAT-20261024-001 使用契约（A02 v13）§4.1。本轮按已批准 V1.2 同步当前行为；未取得外置 A02 原件，不声称其已同步或补签。

## 输出字段（stdout 唯一权威；对象键按字典序；无时间戳；同一输入逐字节一致）

| 字段 | 类型 | 何时存在 | 说明 |
|---|---|---|---|
| `status` | `"valid"`/`"disabled"` | 总是 | |
| `schemaVersion` | `1` | 总是 | 输出格式版本 |
| `validator` | `{name, version}` | 总是 | `task-lifecycle-validate-config` / `"1"` |
| `env` | `{accountHome, home}` | 总是 | `accountHome` 为系统账户查询结果，失败为 `null`；`home` 为实际 `HOME` 字符串，未设为 `""`，不得填入推测值。仅 Windows 未设置 HOME 且账户查询可信时可继续；显式空/冲突与 POSIX 未设仍关闭 |
| `reasons` | array of `{code, detail, layer, path, stage}` | 总是；valid 时为 `[]` | `code` 为 §3.2 码；`stage` ∈ `env`/`locate`/`parse`/`version`/`structure`/`merge`；`layer` ∈ `global`/`project`/`env`；`detail` string（可 `""`）；`path` string（无则 `""`） |
| `layers.global` / `layers.project` | `{exists, path, readable, realpath, sha256}` | `global` 总是；`project` 在给出任一项目参数时存在 | `exists`/`readable`：boolean 或 `null`（未检查：环境阶段失败，或项目参数不全/身份未核实）；`path`：string 或 `null`——`home-unverifiable` 时 global 为 `null`；`home-mismatch` 时 global 为按**账户 home** 计算的预期路径（不使用 `HOME`）；项目参数不全时 project 为 `null`；`realpath`、`sha256`（64 位小写 hex）：不存在/不可读/未检查时 `null` |
| `approvalSources` | array of `{layer, messageId, quote, record}` | 总是 | 仅 `status=valid` 时填每个存在的层（按 global、project 顺序）；disabled 时**固定为 `[]`** |
| `effective` | object 或 `null` | 总是；disabled 时 `null` | |
| `effective.delegation` | `{categories, enabled, executors}` | valid 时 | categories 四键齐全，每项 `{sourceLayer, value}`；`enabled` 为 `{sourceLayer, value}`；v11（K4）：`executors.<id>` = `{command, model, reasoningEffort}`，后两项省略时输出 `null`（宿主默认） |
| `effective.review` | `{enabled, fallback, hosts}` | valid 时（v11，K4） | `enabled` 为 `{sourceLayer, value}`；`fallback` 三键固定值；`hosts` 为配置顺序的 `{command, id, model, reasoningEffort}` 数组（`model`/`reasoningEffort` 省略为 `null`），effective enabled=false 时为 `[]`；全局与项目均省略 `review` 时输出 `{enabled:{sourceLayer:"default",value:false}, fallback:<三项固定值>, hosts:[]}` 【Rocky 13:22 已定 D4（按推荐项）】 |
| `effective.workflowDepth.executionDefault` | `{sourceLayer, value}` | valid 时 | 无默认时 `value: null`、`sourceLayer` 为 `default` 或执行移除的 `project` |
| `legacy` | array of `{detail, file, kind, layer, line, suggestedJson}` | 总是，可 `[]` | `file` 绝对路径；`kind` ∈ `delegation-section`/`depth-execution-default`/`legacy-check-skipped`；`detail` string（仅 skipped 时非空，否则 `""`）；`layer` ∈ `global`(工作区约定)/`project`；`line` 正整数（1 起；skipped 为 0）；`suggestedJson`：kind 为 `delegation-section`/`depth-execution-default` 时为 object（该层等价 JSON 片段，无法推断的字段留 `null`），kind 为 `legacy-check-skipped` 时为 `null`；排序 `layer` → `file` → `line` → `kind` |

- `sourceLayer` ∈ `global`/`project`/`default`。
- `effective.delegation.enabled.value` 与 `effective.review.enabled.value` 均为 boolean；enabled 直接为布尔、缺 value 或 value 为字符串等错误类型均拒收为 `validator-failed`，不按对象真值或字符串推测。
- 消费方先校验上述必有字段与类型，不符即 `validator-failed`。

任一字段缺失、类型不符（如 `effective.review.enabled` 写成布尔值而非 `{sourceLayer, value}`）→ `validator-failed`，整体关闭。

消费 enabled 时分别比较 `effective.review.enabled.value === true` 与 `effective.delegation.enabled.value === true`；不能对 enabled 对象取真值。保留各自 `sourceLayer`，审查开启不启用编码委派，某一用途关闭不取消其他有效设置。

## 原因码（`reasons[].code` 合法域，即使用契约 §3.2「脚本输出的码」）

- `invalid-argument`、`home-unverifiable`、`config-location-forbidden`、`config-missing`、`project-identity-unverified`
- `config-unreadable`、`config-parse-error`、`duplicate-key`、`schema-version-unknown`、`missing-field`
- `invalid-type`、`invalid-value`、`unknown-field`、`forbidden-mapping`、`approval-source-missing`
- `project-layer-widening`；提示类 `legacy-markdown-ignored`（不影响 status）

## `fallback` 固定值（`effective.review.fallback`，三键逐字）

- `noIndependentSession`: `"blocked-needs-evidence"`
- `oneExternal`: `"host-fresh-session-else-isolated-sessions-of-external"`
- `zeroExternal`: `"isolated-host-sessions"`

上表中“§3.2 码”“三键固定值”均指本文件以上两节；任一值不在合法域 → `validator-failed`。
