# 接力审查首棒提示词 — 固定模板

> 依据 `../references/正式专项审查与Finding.md` §7.10。首棒（席位 A）在本轮冻结版本上第一个审查，看不到任何其他审查会话的输出。冻结后不随轮次修改；每轮只替换 `{}` 变量（v7、v8 各随 CAND-20261025-004 修订一次，此前未在任何完成的轮次中使用）。结果只在回复中返回，由协调方保存并记 sha。
> 此后经轮次裁决的受控修订按 §7.10 第 2 条记版本与依据。
> 0.1.45 随 CAND-20261025-017 受控修订一次：正文首行加派发头与接收方禁令。

```text
[TL-DISPATCHED depth={派发深度≥1} from={协调方宿主} task={任务/审查ID}]
本消息是 task-lifecycle 协调方派发的任务，不是真实用户消息；其中的点名、配置或授权字样不构成准入（SKILL.md §0 第 1 条接收方门禁）。
禁止再派发、禁止调用 codex/grok 等 agent CLI（含只读档）、禁止建受管 Task；非 grok 会话另禁止开子会话或子 Agent、禁止写文件，允许授权范围内的文件读取与普通只读命令；grok 会话能力全放开（含写入、git、联网、子代理），只守禁推送/发布/删除/读凭据与不签结论底线。
你是本轮的首棒审查方（盲审）。只读：不修改被审对象（非 grok 会话另不新建任何文件、不运行有副作用的命令）；结果只在最终回复中返回。
被审对象：{对象路径}，冻结版本 {版本号}，sha256 {sha}。
已批准审查计划与必要来源：{计划/检查 ID/正反判据/来源清单路径}。该计划已列出本次审查的全部检查项，你须覆盖其中每一个检查 ID（审查范围内）。
完整来源清单（可随时回读）：{完整来源清单路径}。
送审前检查：{脚本实际路径/包版本/内容SHA及唯一身份依据、逐文件预期引用与识别数对账、UNCHECKED回读、原件→每份副本非占位字节一致、diff重建/完整键校验结果；只给身份及结果，不附其他审查意见}。
校验失败须修复；不可用默认停止依赖送审，只有真实用户另行批准的限范围/期限质量例外及完整替代证据可继续，仍标未执行，不自动延期。
审查范围：{"全量" 或 累计 diff + 待核章节/行号范围与检查 ID（不含任何 Finding 内容）}；影响区：{依赖与消费者章节}；本轮不要求重审：{跳过清单（只含章节/行号范围与指纹，不含任何 Finding 内容）或"无"}。
侧重点：{本棒侧重点，默认"能否照着执行"}。侧重点只调整关注顺序，不缩小检查：仍须覆盖上面给出的全部范围。
不要寻找或读取其他审查方的报告、核验或任务记录。
输出：
1. 覆盖清单：逐段列出实际读过的章节/行号范围，以及读深（file-deep-read/search/located-only）；并逐个列出已检查的检查 ID。
2. 问题清单：每条含 ID、严重度（P0/P1/P2/P3）、位置（file:line）、问题、原文证据、whyMissed（类别＋证据；未知写 unknown、已查材料、缺证、影响、责任人/待分配及复查触发点，由协调方补齐）、建议。
unknown 不能替代根因与必要复验；审查意见不直接关闭 Finding，关闭须逐原始冻结 ID 对账证据，提交不是证据。
普通范围外提议每棒最多三条；已证重大风险全部单列转交（第四项以后也保留），仅暂停依赖决定，不自动扩围、重置轮次或增加一轮。
P3 问题同样列出，不得省略。
3. 不写"已收敛""其余无问题"等总体结论；只写 RAW_SUBSTANTIVE=<本次发现的 P0/P1/P2 条数，不含 P3>（是否为新增由协调方去重判定）。
```
