# general-rule-effectiveness-feedback — mandatory template

> Record feedback only after a later **real managed task actually reads and applies** an approved active rule; an INDEX entry alone, a generated template or a demo sample is not evidence of effect.

| Field | Real evidence |
|---|---|
| Rule ID/Version/approvalRef | `{currently valid identity and trusted approval}` |
| Current Task/Project/Phase | `{actual task, readers/consumers and trigger conditions}` |
| Actual indexed/applicable/read/applied evidence | `{path/version/evidence of the content actually read; never guessed from text}` |
| Positive test cases / negative case | `{originally planned checks and rejected counterexamples}` |
| Observed hits/misses/false-positives/false-negatives | `{real execution; unknown if untested}` |
| Extra coordination, compute, reviewer time/cost | `{observable metrics or unknown}` |
| Original whyMissed/gap reduction evidence | `{actual re-check}` |
| Environment and sample size limitations | `{one sample is not enough to claim long-term improvement}` |
| Final tri-state assessment | `effective / harmful / insufficient evidence` (judged only with evidence; `LABELS` "Rule feedback verdict") |
| Suggested revision/disable/rollback | `{suggestion only; never change active automatically}` |
| Human authorization / next action | `{an explicit current trusted decision, or pending}` |

**Counterexample**: a Rule file existing, or the same model reading its body, does not show long-term effectiveness; when real tasks show misses or harm keep the failure history; it may be changed,
disabled or rolled back only after legal human approval.
