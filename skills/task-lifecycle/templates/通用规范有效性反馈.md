# 通用规范有效性反馈 — 强制模板

> 只在后续**真实受管任务确实读取并应用**已经获批准的 active 规则后记录反馈；INDEX仅有条目、生成模板或演示样例都不是效果证据。

| 字段 | 真实证据 |
|---|---|
| Rule ID/Version/approvalRef | `{当前有效身份与可信批准}` |
| Current Task/Project/Phase | `{实际任务、读者/消费者与触发条件}` |
| Actual indexed/applicable/read/applied evidence | `{实际读取内容的路径/版本/证据，不得凭文字猜测}` |
| Positive test cases / negative case | `{原计划的检查与拒收反例}` |
| Observed hits/misses/false-positives/false-negatives | `{真实执行；无测写unknown}` |
| Extra coordination, compute, reviewer time/cost | `{可观察指标或unknown}` |
| Original whyMissed/gap reduction evidence | `{实际复核}` |
| Environment and sample size limitations | `{一个样本不足称长期改善}` |
| Final tri-state assessment | `有效 / 有害 / 证据不足`（有证据才判断） |
| Suggested revision/disable/rollback | `{仅建议，不能自动改active}` |
| Human authorization / next action | `{明确当前可信决定或者pending}` |

**反例**：Rule 文件存在或同一模型读完其正文，不说明长期有效；真实任务显示漏检或有害时应保留失败史，经过合法人批后才能修改、停用或回滚。
