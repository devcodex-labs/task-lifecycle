# 通用规范吸纳候选 — 强制模板

> **强制资源**：候选默认仅在候选库 `candidates/pending/`（插件源仓库根目录 `candidates/` 下，不在技能目录内）以 Markdown 保存，绝不自动 active，不因 Auto/模型自审生效。仅确有可泛化证据才创建，项目特殊数据/个人隐私不得纳入。

| 字段 | 内容 |
|---|---|
| Candidate ID / Rule ID / Version / Proposed status | `{新候选或既有规则升级；唯一真实身份；candidate}` |
| Actual Finding IDs / Source Evidence | `{实际任务/版本/真实来源；或触发来源（用户纠正/更优方案/验收被拒/交付后缺陷/自我撤回/反复变更/复审停滞）原文与已核实根因}` |
| `defectRootCause` / `whyMissed` / `controlFailure` | `{具体缺陷成因、先前控制为何失效}` |
| Cross-task Generalization Qualification | `{为何跨项目/任务可复用；真实证据与假设分开}` |
| Applicable Example A (distinct) | `{可执行触发、检查与预期；若为假设明示}` |
| Applicable Example B (distinct) | `{与A不同的合理情境}` |
| Non-applicable Counterexample | `{哪种情形不应套用，避免泛化过度}` |
| Entry/Match Conditions | `{任务阶段/项目/风险/触发，不含用户私密标识}` |
| Concrete Review Action / Failure Rule | `{可由后续任务真实检验的步骤与拒收结果}` |
| Earlier Checkpoint / Introduction & Maintenance Cost | `{应前移至何阶段/动作之前、引入/执行/维护成本及估计依据；不可观察写unknown}` |
| Existing Rule/Reference Comparison | `{重复/冲突/合并/替换分析}` |
| Scope & Privacy Exclusion | `{项目特有/凭据/敏感输出必须排除}` |
| Verification Strategy & E4 | `{D/A/I/H方法及是否真实运行；默认unverified}` |
| Rollback/Retirement Plan | `{active/INDEX/history一致、实际用户权限和消费者}` |
| Required Human Approval | `{待真实用户逐条决定，不能写默认confirmed}` |
| Current Status / Next Action | `candidate/not-eligible/blocked，说明理由` |

## 文件级自审（真实填写）

候选和对应审查记录均保存于候选库 `candidates/`（待吸纳入 `candidates/pending/`、已吸纳入 `candidates/archived/`、已下架入 `candidates/rejected/`，`candidates/` 根目录不放候选），
未获真实人工晋级前不作为工作流执行规则读取。按 `../references/通用规范吸纳与自我进化.md` 复核前移检查点、成本、可重复正反验收和回退，无法收敛不晋级。
