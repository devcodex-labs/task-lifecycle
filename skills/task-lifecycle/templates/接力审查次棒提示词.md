# 接力审查次棒提示词 — 固定模板

> 依据 `../references/正式专项审查与Finding.md` §7.10。次棒（席位 B）在首棒交卷、协调方核实后，审同一冻结版本；只通过下方变量拿到首棒已核实清单。冻结后不随轮次修改；每轮只替换 `{}` 变量（v7、v8 各随 CAND-20261025-004 修订一次，此前未在任何完成的轮次中使用）。结果只在回复中返回，由协调方保存并记 sha。
> 此后经轮次裁决的受控修订按 §7.10 第 2 条记版本与依据。

```text
你是本轮的次棒审查方。只读：不修改、不新建任何文件，不运行有副作用的命令；结果只在最终回复中返回。
被审对象：{对象路径}，冻结版本 {版本号}，sha256 {sha}（与首棒相同）。
已批准审查计划与必要来源：{计划/检查 ID/正反判据/来源清单路径}。该计划已列出本次审查的全部检查项，你须覆盖其中每一个检查 ID（审查范围内）。
完整来源清单（可随时回读）：{完整来源清单路径}。
审查范围：{"全量" 或 累计 diff + 待核章节/行号范围与检查 ID（不含任何 Finding 内容）}；影响区：{依赖与消费者章节}；本轮不要求重审：{跳过清单（只含章节/行号范围与指纹，不含任何 Finding 内容）或"无"}。
侧重点：{本棒侧重点，默认"漏洞与冲突"}。侧重点只调整关注顺序，不缩小检查：仍须覆盖上面给出的全部范围。
下面是本轮首棒的已核实问题清单（每条只含 ID、位置、问题、证据、协调方裁决；已删去总体结论、whyMissed 和建议）：
{首棒已核实清单}
这份清单不是你的审查范围：你必须对上面给出的全部范围独立审查并输出自己的覆盖清单，不得只审清单条目，也不得因清单未提及就认为没有问题。
除上面内联的清单外，不要寻找或读取其他审查方的报告、核验或任务记录。
输出：
1. 覆盖清单：逐段列出实际读过的章节/行号范围，以及读深（file-deep-read/search/located-only）；并逐个列出已检查的检查 ID。
2. 对首棒条目：逐条标 同意 / 异议（必须附原文证据）/ 补充（遗漏的同类实例或更准确的位置）。
3. 新问题清单（首棒清单之外）：每条含 ID、严重度（P0/P1/P2/P3）、位置（file:line）、问题、原文证据、whyMissed（为何首棒及先前审查漏掉，附证据；证据不足写"待核验"及缺什么）、建议。
P3 问题同样列出，不得省略。
4. 不写"已收敛""其余无问题"等总体结论；只写 RAW_SUBSTANTIVE=<新问题中 P0/P1/P2 条数，不含 P3>；DISPUTE=<异议条数>。
```
