# 已下架候选（archived/）

本目录存放已下架的通用规范吸纳候选，只作历史查阅，不是执行规则，也不再参与审查或晋级。

## 下架流程
1. 下架须有记录依据（撤回、被取代或经审查不再吸纳）；涉及已生效规则的停用另按 `skills/task-lifecycle/references/通用规范吸纳与自我进化.md` 由真人决定。
2. 将候选文件及其审查记录从 `candidates/` 移入本目录（`git mv`，保持文件名与编号不变，不改正文）。
3. 在本目录下表追加一行，状态写“已下架”，写明下架时间（含时区）、原因与依据。
4. 从 `candidates/README.md` 候选清单删除对应行。
